\begin{abstract}
Accurate spatial-temporal forecasting of atmospheric pollutant dispersion is often constrained by sparse physical monitoring stations. Standard deep learning architectures frequently produce unphysical boundary predictions when extrapolating into unmonitored spatial gaps. In this work, we propose AeroGraph-PINN, a Physics-Informed Neural Network architecture that integrates the 2D Advection-Diffusion Partial Differential Equation (PDE) directly into the neural loss function. Evaluated across a 50,000 point spatio-temporal domain using only 200 sparse sensor observations, AeroGraph-PINN achieves a Mean Squared Error (MSE) of 0.0315 and an $R^2$ score of 0.9274, representing a 40.8\% reduction in MSE compared to purely data-driven baselines.
\end{abstract}

\section{Introduction}
Atmospheric pollution modeling requires solving non-linear transport dynamics across complex spatial domains. Traditional numerical PDE solvers require dense grid discretizations and precise boundary conditions, whereas purely data-driven neural networks lack physical constraints and overfit sparse observation points. AeroGraph-PINN bridges this gap by enforcing conservation laws during network optimization.

\section{Methodology}
\subsection{Governing PDE}
The atmospheric concentration field $C(x, y, t)$ is modeled using the 2D Advection-Diffusion equation:
\begin{equation}
\frac{\partial C}{\partial t} + u \frac{\partial C}{\partial x} + v \frac{\partial C}{\partial y} = D \left( \frac{\partial^2 C}{\partial x^2} + \frac{\partial^2 C}{\partial y^2} \right)
\end{equation}
where $u = 0.5 \text{ km/h}$ and $v = 0.3 \text{ km/h}$ represent wind velocity components, and $D = 0.05$ is the diffusion coefficient.

\subsection{Loss Function Optimization}
The total loss function $\mathcal{L}_{\text{total}}$ combines sensor observation error $\mathcal{L}_{\text{data}}$ with physics residual penalties $\mathcal{L}_{\text{pde}}$:
\begin{equation}
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{data}} + \lambda \mathcal{L}_{\text{pde}}
\end{equation}
where $\lambda = 0.1$ balances the residual physics constraint evaluated across 2,000 collocation points.
